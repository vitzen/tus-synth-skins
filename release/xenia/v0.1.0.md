# Simpless for Xenia v0.1.0

## Что нового
- Первый релиз скина **Simpless** для **Xenia** (The Usual Suspects)
- Clean, minimal re-design интерфейса: мягкие rounded панели на тёмном фоне
- Палитра: мягкий медный-оранжевый (приглушённый цвет Xenia), кремовый текст, красный акцент
- Шрифт Gabarito (SIL Open Font License) — включён в архив
- Все страницы работают как в дефолтном скине: Main, Mod, Arp/FX, Multi, Wave, Patch Manager

## Установка
1. Скачайте `Simpless-Xenia-v0.1.0.zip`
2. Распакуйте — получится папка **Simpless/**
3. Положите её в директорию скинов Xenia:
   - Windows: `%APPDATA%\The Usual Suspects\Xenia\skins\`
   - macOS: `~/Library/Application Support/The Usual Suspects/Xenia/skins/`
4. В меню скинов Xenia выберите **Simpless**
