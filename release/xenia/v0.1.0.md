# Simpless for Xenia v0.1.0

## What's New
- First release of **Simpless** skin for **Xenia** (The Usual Suspects)
- Clean, minimal re-design: soft rounded panels on dark background
- Palette: muted copper-orange (Xenia hardware tone), cream text, red accent
- Gabarito font (SIL OFL) included
- All pages work like default skin: Main, Mod, Arp/FX, Multi, Wave, Patch Manager

## Installation
1. Download `Simpless-Xenia-v0.1.0.zip`
2. Unzip — you get folder **Simpless/**
3. Place it in Xenia skins directory:
   - Windows: `%APPDATA%\The Usual Suspects\Xenia\skins\`
   - macOS: `~/Library/Application Support/The Usual Suspects/Xenia/skins/`
4. Select **Simpless** in Xenia skin menu
