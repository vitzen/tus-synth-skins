# Simpless for Xenia v0.1.0 / Simpless для Xenia v0.1.0

## What's New / Что нового
- First release of **Simpless** skin for **Xenia** (The Usual Suspects) / Первый релиз скина **Simpless** для **Xenia** (The Usual Suspects)
- Clean, minimal re-design: soft rounded panels on dark background / Чистый, минималистичный редизайн: мягкие скруглённые панели на тёмном фоне
- Palette: muted copper-orange (Xenia hardware tone), cream text, red accent / Палитра: приглушённый медный-оранжевый (цвет железа Xenia), кремовый текст, красный акцент
- Gabarito font (SIL OFL) included / Шрифт Gabarito (SIL OFL) включён в архив
- All pages work like default skin: Main, Mod, Arp/FX, Multi, Wave, Patch Manager / Все страницы работают как в дефолтном скине: Main, Mod, Arp/FX, Multi, Wave, Patch Manager

## Installation / Установка
1. Download `Simpless-Xenia-v0.1.0.zip` / Скачайте `Simpless-Xenia-v0.1.0.zip`
2. Unzip — you get folder **Simpless/** / Распакуйте — получится папка **Simpless/**
3. Place it in Xenia skins directory / Положите в директорию скинов Xenia:
   - Windows: `%APPDATA%\The Usual Suspects\Xenia\skins\`
   - macOS: `~/Library/Application Support/The Usual Suspects/Xenia/skins/`
4. Select **Simpless** in Xenia skin menu / В меню скинов Xenia выберите **Simpless**
