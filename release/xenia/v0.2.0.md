# Simpless for Xenia v0.2.0

## What's New
- Redesigned logo block with right border and rounded corners
- Updated screenshots

## Installation
1. Download `Simpless-Xenia-v0.2.0.zip`
2. Unzip — you get folder **Simpless/**
3. Place it in Xenia skins directory:
   - Windows: `%APPDATA%\The Usual Suspects\Xenia\skins\`
   - macOS: `~/Library/Application Support/The Usual Suspects/Xenia/skins/`
4. Select **Simpless** in skin menu
