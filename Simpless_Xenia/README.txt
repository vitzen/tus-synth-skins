Simpless is a clean, minimal re-design of the Xenia interface. The goal was
a calm, uncluttered look that keeps every control easy to read: instead of
the busy hardware-style graphics, the synth is laid out as a set of softly
rounded panels on a dark background.

LOOK
Each section (oscillators, waves, mixer, filters, envelopes, modulation
slots and so on) sits on its own rounded panel with a dark tab heading that
names it. Knobs are drawn as simple cream caps surrounded by a thin tick
ring, so their value can be read at a glance, and all labels use the thin,
friendly Gabarito typeface. Drop-down menus and buttons share the same
rounded, dark style, and active states are shown with red LEDs and buttons.

COLOURS
The palette is built around a soft copper-orange for the panels - a
toned-down version of the Xenia hardware colour - combined with cream text
and controls, a dark frame around the whole window, and red as the single
accent colour for anything that is switched on.

COMPATIBILITY
The skin keeps the element ids and the structure the plugin expects, so every
page (Main, Mod, Arp/FX, Multi, Wave and the patch manager) works as in the
default skin: all controls sit exactly where the plugin looks for them.

INSTALLATION
Put the 'Simpless' folder into the Xenia 'skins' directory and select
"Simpless" in the skin menu.
